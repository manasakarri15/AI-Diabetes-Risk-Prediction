# AI-Based Diabetes Risk Prediction

An AI-based machine learning application that predicts diabetes risk using patient health information.

## Project Overview

This project uses an XGBoost machine learning model to predict diabetes risk based on patient information such as:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

The application also uses SHAP (SHapley Additive exPlanations) to explain why the model made a particular prediction.

## Features

- Diabetes risk prediction
- Risk probability percentage
- Low Risk / High Risk classification
- SHAP-based explainable AI
- Interactive Streamlit interface
- XGBoost machine learning model

## Technologies Used

- Python
- XGBoost
- Streamlit
- SHAP
- Pandas
- NumPy
- Scikit-learn
